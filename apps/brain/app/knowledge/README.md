# Knowledge Loader

The knowledge loader reads structured markdown files from `data/knowledge` and supports:

* category listing
* metadata-aware indexing
* relevance and semantic-style retrieval
* validation, trust, and quarantine checks
* source reporting and gap detection
* relationship graph generation
* markdown and JSON ingestion
* analytics and reindexing

This remains local-first, but it now preserves a clean path for richer retrieval and future ingestion adapters.
