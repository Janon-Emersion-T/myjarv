# Rust Core

The Rust workspace is located in `apps/rust-core`.

Crates:

* `jarvis_file_guard`
* `jarvis_command_guard`
* `jarvis_logger`
* `jarvis_system_info`
* `jarvis_text_utils`

Current integration mode is CLI-first. Later phases can wrap these tools from Python or run them as sidecar services.
