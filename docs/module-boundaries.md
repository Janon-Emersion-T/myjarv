# Module Boundaries

## Rule
No module may directly modify another module's private storage.

## Core Modules
- Task Manager
- Routing Engine
- Approval Engine
- Memory Store
- Knowledge Store
- Tool System
- Security Engine
- Project Manager
- Developer Mode
- Business Automation
- Workflow Replacement
- Collaboration Engine
- Voice Engine
- Self-Learning Engine
- Jarvis OS

## Each module must define:
- purpose;
- owner;
- public API;
- storage path;
- events emitted;
- approval requirements;
- test file.
