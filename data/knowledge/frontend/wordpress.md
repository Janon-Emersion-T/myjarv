# WordPress Delivery Playbook

- Favor maintainable theme and plugin choices over heavy page-builder lock-in.
- Document editor workflows so the client can manage routine content safely.
- Validate forms, caching, backups, and security plugins before go-live.
- For WooCommerce projects, verify taxes, shipping, payment, and transactional emails end to end.
