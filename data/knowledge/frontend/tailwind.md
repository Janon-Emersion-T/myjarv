# Tailwind Usage Notes

- Treat utility strings as design decisions, not random accumulations.
- Reuse semantic component wrappers for repeated panel, badge, and layout patterns.
- Promote color, spacing, and motion tokens into config when repetition appears.
- Pair Tailwind convenience with accessibility checks for contrast and focus.
