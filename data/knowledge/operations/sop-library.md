# Reusable SOP Library

- Each SOP should define trigger, owner, inputs, steps, review gate, and completion evidence.
- Prefer concise operator checklists over abstract prose when work is time-sensitive.
- Revise SOPs after incidents, missed expectations, or major tool/process changes.
