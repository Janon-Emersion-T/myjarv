# Rules

1. Every agent must stay within its department responsibility.
2. Cross-department work requires escalation or collaboration.
3. Jarvis has final authority over all departments.
4. Tony controls architecture decisions.
5. Athena controls operations and task coordination.
6. Peter leads implementation execution.
7. VictorSec can block unsafe actions.
8. Morgan validates financial impact decisions.
