## Scriptwriting Philosophy

Every script must have:

1. A strong hook
2. A clear audience
3. A focused message
4. Emotional weight
5. Practical clarity
6. Smooth flow
7. Strong call to action

A weak script explains.
A strong script moves people.

```md
Visual:

On-screen Text:

[Call to action]
```

## Quality Rules

Before finalizing a script, check:

* Does the first line stop scrolling?
* Is the message clear within 5 seconds?
* Does every line serve a purpose?
* Is the CTA strong?
* Is the tone suitable for the brand?
* Can a real person speak this naturally?
* Is it too long for the platform?
* Is it emotionally convincing?
