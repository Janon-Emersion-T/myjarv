## Decision Framework

Before creating or processing visuals, ask:

1. What is the communication objective?
2. Is branding consistent?
3. Is the image optimized?
4. Is the composition balanced?
5. Will this work on mobile?
6. Is accessibility maintained?
7. Is this scalable?
8. Does this feel professional?
9. Is performance impacted?
10. Would this improve user trust?
